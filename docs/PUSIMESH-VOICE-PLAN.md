# PusiMesh Voice — план и решения (Ф6-подмножество)

> Решения заказчика 2026-10-18: **Opus как в Xiaozhi**; клип **≤10 с**;
> провод — **новый PusiMesh GATT-носитель поверх mesh-EXT** (не CoPhone, не
> Bulk); запись на устройстве — **с экрана ЧАСЫ (DESK)**, голосовые в истории
> **Чата**; при отправке с телефона следом уходит **текст распознанного**
> (у устройства STT нет). Без хранения аудио в истории (экономия памяти).

## 1. Кодек

- **Opus, 16 кГц, mono, кадр 60 мс** (`OPUS_APPLICATION_VOIP`), как у Xiaozhi
  (`esp_opus_enc`, `ESP_OPUS_BITRATE_AUTO`). Библиотека в PIO —
  **`sh123/esp32_opus@1.0.3`** (полный libopus, сборка под S3 проверена:
  +~330 КБ флеша, ~20 КБ RAM; app-слот 4 МБ, занято 1.8 МБ — места хватает).
- Клип ≤10 с ⇒ ≤167 кадров, ~15–20 КБ (≤32 КБ потолок). Сырой PCM по проводу
  **никогда**.
- Хост-тест «энкод→декод→энкод» на векторах — в `test/` (без радио).

## 2. Провод — mesh-EXT (sealed фразой сквада)

Кадры — обычный **MeshFrame v2**, kind `K_EXT`, запечатаны ключом сквада;
отправитель — `nodeId` (как чат). Новые под-виды (реестр уже есть в
`meshframe_v2.h`):

| sub | имя | плейнтекст |
|---|---|---|
| 11 | `S_VOICE_MANIFEST` | `[blobId u32][codec 1][rate 1][durMs u16][size u32][sha8 8][chunkCount u16]` |
| 9  | `S_BLOB_CHUNK`     | `[blobId u32][seq u16][bytes…][crc16 2]` |
| 10 | `S_BLOB_ACK`       | `[blobId u32][bitmap…]` (бит на чанк) |

- `codec`: 1 = Opus 16 кГц (задел: 2 = Codec2 3200 для LoRa).
- Приём: собрать чанки в PSRAM-буфер, сверить `crc16` каждого и `sha8` всего;
  воспроизвести; ACK — битмапом (докачка недостающих).
- **Текстовая пара.** При отправке с телефона следом (после манифеста/начала)
  уходит обычный `K_TEXT`/`K_TEXT_CYR` с распознанным текстом — читаемо на
  устройствах без динамика (CYD). У устройства STT нет → только текст от него.

Почему EXT, а не CoPhone/Bulk: совпадает с `docs/PUSIMESH-V2-PLAN.md` §5.4–5.5
и §4 (единый реестр под-видов), транспорт-независим (потом ляжет на ESP-NOW/
LoRa), и переиспользует уже написанный `meshframe_v2` seal/open.

## 3. Носитель — новый PusiMesh BLE-GATT

`BLE-ADV` (27 Б/кадр) голос не тянет. Вводим **отдельный GATT-сервис**
(кубик — peripheral/server; телефон — central/client; роли peripheral у кубика
уже включены ради BLE-OTA).

| сущность | UUID | свойства |
|---|---|---|
| сервис `pusimesh` | `7a1c5e10-4b9d-4f3a-8c22-9e6f0d1a2b00` | — |
| `in`  | `…2b01` | write / write-no-rsp (телефон→кубик) |
| `out` | `…2b02` | notify (кубик→телефон) |
| `ctrl`| `…2b03` | write + notify (open/close/MTU/ping) |

- Кадры режутся по `MTU-3`, на приёмнике собираются по 2-байтовому LE-префиксу
  длины (как в CoPhone §7.4 — сборочный буфер до 1 КБ).
- Не шифруется на уровне GATT: содержимое — уже sealed mesh-кадры (фраза
  сквада). Доступ — только к кубику из свежего ростера/по инвайту.
- Сервис поднимается по запросу (экран ЧАСЫ/ЧАТ), гасится в простое.

## 4. Прошивка — модули (не плодить сущностей)

```
include/meshvoice_v2.h + src/meshvoice_v2.cpp   чистый кодек манифеста/чанков (host-test)
src/voice.cpp            I2S mic+spk (NoCodec 4/5/6 & 7/15/16) + Opus enc/dec + запись/игра
src/pusimesh_ble.cpp     NimBLE GATT-сервер: in/out/ctrl, сборка кадров
src/mesh.cpp             раздача принятых EXT voice/blob в Voice::onFrame()
src/meshtalk.cpp         отправка TTS-текста следом (app-путь), метка «голосовое»
src/ui_desk.cpp          кнопка «Голос» между «РАБОТА 25» и «НАЗАД» + запись
src/ui_chat.cpp          строки голосовых (отправитель+время, без аудио)
include/voice.h, include/pusimesh_ble.h
```

- Чистый кодек (`meshvoice_v2`) не включает `<Arduino.h>` и радио — покрыт
  host-векторами. `malloc` в радио-пути нет: буферы PSRAM/статические.

## 5. UX

**Экран ЧАСЫ (DESK)** — кнопка «Голос» в нижнем ряду, между таймером
(«РАБОТА 25») и «НАЗАД»:
- навёл курсор/нажал и держит BOOT → идёт запись, в центре экрана — стилизованный
  брендированный обратный таймер (кольцо/полоса, MM:SS, ≤10 с);
- отпустил (или таймер кончился) → запись готова;
- **короткое** нажатие BOOT → отправить;
- **долгое** (≥2 с) → отменить, кнопка вернулась.

**Чат (CHAT room)** — голосовые в общем списке: отправитель + время; пометка
«голосовое 0:07» + (если следом пришёл текст) распознанный текст строкой.
Аудио в истории **не хранится**. Входящие играются сразу (динамик есть только
у кубика/zhengchen/Freenove).

**Приложение** — см. `PUSIMESH-V2-TASK-ANDROID.md` (обновлён): виджет-кнопка
записи (hold→таймер, release→стоп с 3-секундной заливкой → авто-отправка или
отмена), бабл над отправителем с плеером (автоплей, закрыть через 5 с) и
распознанным текстом, история в секции Чат, флаг в Настройки→Экран, кнопка
записи в Чате.

## 6. Фазы

1. **V0** `meshvoice_v2` + host-тесты (манифест/чанки/crc/сборка/sha).
2. **V1** libopus в сборке + `voice.cpp` (I2S mic/spk, enc/dec) — тон-тест.
3. **V2** GATT-сервер `pusimesh` + приём/отдача sealed voice/blob.
4. **V3** UI: DESK-кнопка+запись+таймер; CHAT-строки; отправка/приём.
5. **V4** прошить кубик, bench: голосовое кубик⇄кубик не нужно — кубик⇄телефон.
6. **A1** Android: GATT-клиент, запись/плеер/бабл/чат/флаг/STT; бамп версии;
   APK в дашборд `192.168.1.222:44242`.

## 7. Приёмка

- Кубик записывает 10 с на экране ЧАСЫ и отправляет; телефон играет и
  показывает распознанный текст.
- Телефон записывает 10 с → кубик играет; следом кубик видит текст.
- CYD (без динамика) видит текст.
- Никакого сырого PCM в эфире; память истории не растёт от аудио.
