# 07 — Экосистема Pusi-os

## Большая картина

**Pusi** — Personal Ultimate Super Intelligence. Экосистема нативного
софта и железа, где каждый элемент полезен сам по себе, а вместе они
дают вам личную суперинтеллектуальную пару: тело, уши, рот, память
и мозги — все ваши, без чужого сервера между.

```
                      ┌───────────────┐
                      │  Pusi-Server  │   ваш VPS / домашний хост
                      │ ASR–LLM–TTS   │   (опционально)
                      └───────▲───────┘
                              │ WebSocket / HTTP
     ┌────────────────────────┼─────────────────────────┐
     │                        │                         │
┌────┴─────┐            ┌─────┴─────┐            ┌──────┴──────┐
│  Плата   │            │ Телефон   │            │ Desktop Pusi │
│ прошивка │◀──PusiMesh▶│ Pusi app  │◀──PusiMesh▶│ (Linux/RPi)  │
│ PotSquad │            │ (бэкенд)  │            └──────────────┘
└────┬─────┘            └─────┬─────┘
     │    BLE / ESP-NOW       │ BLE
┌────▼─────┐                  ▼
│ Компаньон │          другие телефоны
│ (S3 брелок)│         и настольный брат
└──────────┘
```

Ничего из этого не обязано быть в интернете. Рисунок и есть вся
сеть: устройства говорят друг с другом тем, что у них есть, —
Bluetooth, ESP-NOW или LoRa прямо на месте.

## Кто есть кто

| Имя | Что это | Статус в экосистеме |
|---|---|---|
| **PotSquad** (этот репо) | прошивка для CYD и ESP32-S3 с экраном: детектор + Potsy + сквад | здесь, живёт в `/firmwares/PotSquad` |
| **[Pots](https://github.com/pusi-os/Pots)** (Android) | бэкенд всей системы на телефоне: компаньон, агент, сканер, карта, шара файлов, оверлей | репо `pusi-os/Pots` |
| **Компаньон-прошивка Pusi** | голосовые ESP32-S3 платы: брелоки, кубы, настольные станции (мик + динамик + экран) | базируется на нашем голосовом стеке, совместим с PusiMesh |
| **[PusiDesk](https://github.com/pusi-os/PusiDesk)** | Linux/Windows/macOS: тот же персонаж и агент-мост, локальная память | репо `pusi-os/PusiDesk` |
| **[PusiServer](https://github.com/pusi-os/PusiServer)** | ваш ASR-LLM-TTS сервер, OTA, собственные навыки по MCP | репо `pusi-os/PusiServer`; всегда самохостинг |
| **Potsy** | общий персонаж: один и тот же зверёк во всех приложениях | рисуется одними данными |

Телефон — центр тяжести: на нём память (Obsidian-хранилище), компаньон
с характером и инструменты. Брелок — «уши и рот», который можно
надеть на молнию рюкзака. Прошивка PotSquad — «глаза», которые
смотрят в эфир. Десктоп и сервер — «мощность», когда она нужна.

## Правила экосистемы

1. **Независимость частей.** Каждый элемент полезен отдельно.
   Приложение без прошивки — работает. Прошивка без телефона —
   работает. Сервер без всего прочего — работает, если вы его
   поставили.
2. **Работа без интернета** — базовый случай, не режим
   совместимости. Сквад на пляже не ищет Wi-Fi: у него есть
   Bluetooth и (если повезёт с железом) LoRa.
3. **Совместимость протокола, а не устройств.** PusiMesh-формат
   едет одинаково на всех: прошивка, телефон, десктоп. Смена бренда
   или форм-фактора не ломает чат.
4. **Открытые протоколы, закрытые привычки.** Формат пакетов и
   шифрование описаны; никаких «только наше приложение, только iOS 17+».
5. **Один человек — много устройств.** Ваша память и ваш сквад
   растягиваются на всё железо, которое вы решите носить.
6. **Опциональный сервер.** Всё главное идёт без него.
   Он нужен, когда ваша группа распределена по городам или вам
   нужен более тяжёлый «мозг», чем тот, что в кармане.

## Локальный и облачный интеллект

Компаньон работает с любым OpenAI-совместимым источником:
- **локально** — прямо на телефоне (llama.cpp с подбором модели);
- **свой сервер** — llama.cpp / Ollama на вашем хосте, полный стек
  распознавания и говорения у вас;
- **облако** — тот поставщик, чей ключ вы ввели, и его можно сменить
  в три клика; в коде нет ни одного жёстко вписанного имени
  провайдера.

Совместимость и перенос приводят к простому выводу: ваши данные
не заперты. Память — файлы; конфигурации — файлы; эфирные сообщения — в
вашем телефоне. Хотите сделать экспорт — файлы для того и лежат
открытым текстом.

## Транспорт сообщения (кратким списком)

См. [04-ТРАНСПОРТЫ.md](04-ТРАНСПОРТЫ.md) за подробностями. Вкратце:
BLE — везде; ESP-NOW — на платах, которые его умеют, с релеем на
несколько ходов; WiFi — дома и для обновлений; LoRa — для тех, у кого
километры; протокол через интернет — для мест, где сквад распределён.

## Что появится позже

Строим в этом порядке (порядок фиксируется не датой, а готовностью):

- **Форм-факторы компаньонов** — брелоки, кубики, настольные станции
  (все на ESP32-S3): голос — основная функция, сканер — вторая.
- **Голосовые сообщения в прошивке** — короткий кусок голоса по тем
  же транспортам, что и текст, тем же шифром.
- **Планшеты и десктоп-приложения** — уже прототип на Linux,
  дальше доводка интерфейсов под планшеты.
- **Каталог железа** — список плат, которые мы сами проверяли,
  с готовыми прошивками через web-flasher (без всяких IDE).
- **Радар-сквад** — кооперативное определение направления до
  устройства по нескольким соседям.

## Почему всё это бесплатно и открыто

Потому что приватная среда, приватность в которой — архитектурный
принцип, попросит открытого кода, чтобы читали и проверяли. Всё
лицензировано GPL-3.0: берите, правьте, делитесь так же открыто.
